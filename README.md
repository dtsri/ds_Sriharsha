# 🧠 Trader Behavior & Market Sentiment Analysis

This project explores how trader performance correlates with the **Fear & Greed Index** in the cryptocurrency market using historical market and trading data.

## 🧩 Key Insights

- The market showed a **bias toward Fear and Extreme Fear** conditions.  
- **Weak linear correlation (0.01)** between the Fear & Greed Index and trader profitability.  
- However, **Extreme Greed** periods correlated with the **highest average Closed PnL**.  
- **Fear periods** had the **highest trading volume** but **lower profitability**.  
- **Coin performance** varied significantly across sentiments, highlighting the importance of selective trading.  
- Insights suggest that **contrarian or sentiment-aware** strategies might improve performance.
